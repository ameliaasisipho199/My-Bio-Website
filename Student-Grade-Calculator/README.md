# Student Grade Calculator

## Project Description
The Student Grade Calculator is a Python application developed to help students and educators calculate and manage academic results. The application reads student assessment marks from a CSV file and calculates the final grades using different assessment weightings.

## Programming Language
- Python

## Technologies Used
- Python
- CSV file handling
- Lists and dictionaries
- Graphical User Interface (GUI)
- Input validation and error handling

## Assessment Weightings
The application calculates student results using the following assessment percentages:

- Quiz: 10%
- Project: 20%
- Final Examination: 50%
- Practical: 20%

## Main Features
- Reads student marks from a CSV file.
- Calculates weighted final grades.
- Stores and processes student assessment information.
- Validates user input.
- Handles errors.
- Provides a graphical user interface.

## Purpose
The purpose of this project is to demonstrate Python programming, file handling, data management and basic application development skills.

## How to Run
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure Python is installed.
4. Open the main Python file.
5. Run the application.
